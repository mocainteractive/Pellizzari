# ANALISI RFM PELLIZZARI, CATEGORIE PER SEGMENTO

Report interattivo che analizza le categorie merceologiche più acquistate dai segmenti RFM di Pellizzari, mappate sulla tassonomia del sito negozipellizzari.it. Include una scheda di confronto e una scheda per ciascun segmento: Da Non Perdere, Promettenti, Nuovi Clienti, Campioni.

Il file `index.html` è autonomo, non richiede altri file, e si apre in qualsiasi browser.

## COME PUBBLICARLO SU GITHUB PAGES

- Crea un nuovo repository su GitHub, ad esempio `pellizzari-rfm-categorie`
- Carica il file `index.html` nella radice del repository, insieme a questo `README.md`
- Vai in Settings, poi nella voce Pages
- Alla voce Source scegli Deploy from a branch, seleziona il branch `main` e la cartella radice `/root`, poi salva
- Dopo circa un minuto l'artifact sarà online all'indirizzo `https://TUONOME.github.io/pellizzari-rfm-categorie/`
- Condividi quel link con chi vuoi

## COME CONDIVIDERLO SENZA GITHUB PAGES

- In alternativa puoi inviare direttamente il file `index.html`, che funziona anche aperto in locale con un doppio clic
- Oppure puoi caricarlo su un qualsiasi servizio di hosting statico

## NOTE

- Il report carica il font Figtree da Google Fonts e il logo Moca dal sito mocainteractive.com, quindi serve una connessione a internet per visualizzarlo con lo stile corretto
- I dati sono al netto dei resi, con il tasso di reso calcolato a parte, periodo di riferimento indicato in ogni scheda
- Se il repository è pubblico, il report sarà visibile a chiunque abbia il link, valuta un repository privato se i dati non devono essere diffusi
